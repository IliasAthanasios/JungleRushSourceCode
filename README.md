# JungleRushSourceCode

Source code developed for **Jungle Rush**, a 3D third-person
platform game created in Unity as part of a Bachelor's Thesis
at the Department of Informatics, Ionian University.

## Development Environment

- Unity 6000.4.7f1
- Windows 11
- Universal Render Pipeline (URP)
- C#
- Cinemachine 3.1.7
- Input System 1.19.0
- AI Navigation 2.0.12

## Main Features

- Third-person character controller
- Camera-relative movement
- Jump, Double Jump and Coyote Time
- Spin Attack and Ground Pound
- Landing Shadow system
- Checkpoint and world-state restoration
- Enemy AI using NavMesh
- Moving and collapsing platforms
- Cinemachine cutscenes
- Multi-phase Boss Fight
- Input rebinding
- Audio and settings management
- Scene transitions and loading screens

## Repository Structure

The source code is divided into separate folders according to
the subsystem in which each script is used.
